# Cozinha Calc

Calculadora de cozimento (front-end puro): cru ↔ cozido, água, temperos em colheres, macros e micros, receitas com Gemini.

- Abra `index.html` no navegador (duplo clique).
- Em **Configurações**, cole sua `GEMINI_API_KEY` (fica só no navegador).
- Testes dos cálculos: `node test.js`
- Valores nutricionais: `data.js` (referências arredondadas TACO/USDA — ajuste à vontade).
- **Nunca** suba o arquivo `.env` para o Git (já está no `.gitignore`).
